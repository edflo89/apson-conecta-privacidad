APSON Conecta

Política de Privacidad

Última actualización: 8 de octubre de 2026

APSON Conecta es una aplicación móvil orientada a proporcionar información comunitaria sobre los tiempos de espera en los cruces fronterizos entre Agua Prieta, Sonora, México, y Douglas, Arizona, Estados Unidos.

Esta política explica qué información utiliza la aplicación, con qué finalidad y cómo pueden los usuarios comunicarse con el responsable.

2. Información utilizada

Según las funciones que utilice cada usuario, APSON Conecta puede tratar:

  • Datos de ubicación del dispositivo, cuando el usuario concede el permiso correspondiente.
  • Reportes voluntarios sobre la longitud y el avance de las filas fronterizas.
  • Dirección, tipo de fila, fechas, horas y duración de los cruces registrados.
  • Un identificador generado por la aplicación para asociar registros y ayudar a controlar duplicados.

3. Uso de la ubicación

La ubicación se utiliza para apoyar las funciones de detección y seguimiento de cruces fronterizos. El usuario puede administrar los permisos de ubicación desde la configuración de su dispositivo.

En las funciones de registro de cruces revisadas, las coordenadas GPS se utilizan para comprobar la proximidad a zonas de cruce y no se incluyen en los registros enviados a la base de datos.

4. Finalidades del tratamiento

  • Mostrar información comunitaria sobre las filas.
  • Calcular estimaciones de tiempos de espera.
  • Registrar la duración de los cruces.
  • Evitar reportes duplicados o excesivamente frecuentes.
  • Mejorar el funcionamiento del servicio.

5. Almacenamiento de datos

La aplicación conserva información de cruces y reportes en el almacenamiento local del dispositivo. También utiliza Supabase como infraestructura para recibir y consultar determinados registros compartidos con la comunidad.

Algunos registros pueden quedar pendientes de sincronización cuando no hay conexión a internet.

6. Información compartida

Los reportes comunitarios y los tiempos de cruce pueden utilizarse para generar estimaciones que se muestran a otros usuarios.

La aplicación no solicita el nombre completo del usuario para enviar reportes de filas o registrar tiempos de cruce.

7. Conservación y eliminación

La información se conserva según las necesidades operativas del servicio. Los usuarios pueden solicitar información sobre sus datos o pedir su eliminación escribiendo a apsonconecta@gmail.com .

Para localizar un registro puede ser necesario proporcionar información suficiente que permita identificarlo, sin solicitar datos innecesarios.

8. Seguridad

APSON Conecta busca aplicar medidas técnicas razonables para proteger la información frente al acceso o uso no autorizado. Sin embargo, ningún sistema puede garantizar seguridad absoluta.

9. Servicios de terceros

APSON Conecta utiliza Supabase para funciones relacionadas con el almacenamiento y consulta de información. Este proveedor puede procesar datos técnicos necesarios para prestar sus servicios.

Puedes consultar la política de privacidad del proveedor en supabase.com/privacy .

10. Menores de edad

APSON Conecta no está dirigida específicamente a niños y no busca recopilar deliberadamente información personal de menores.

11. Cambios a esta política

Esta política podrá actualizarse cuando cambien las funciones de la aplicación o el tratamiento de información. La fecha de actualización se indicará al inicio de esta página.

12. Contacto

Para dudas sobre privacidad, acceso, corrección o eliminación de datos, escribe a: apsonconecta@gmail.com .
